# Portfolio Roadmap

## Goal

Build three polished, fictional-but-realistic demo projects. Clearly label them as concept work. The point is to show the quality of work a real client can expect.

## The first three demos

1. **A premium barbershop or salon website**
   - Booking call-to-action, services, gallery, location, testimonials
   - Shows that you can create a modern local-business site

2. **A fashion brand or online-store concept**
   - Product collection, product page, cart experience, strong mobile design
   - Shows design taste and e-commerce thinking

3. **A personal brand / creator portfolio**
   - About, work, services, social links, contact form
   - Shows how you help creators look professional online

## How GetLayers fits

Use a GetLayers template or section as a visual starting point, then make it yours:

- Rewrite all copy for the fictional brand.
- Create a new colour system and logo treatment.
- Replace imagery and sections to match the business.
- Build it cleanly in Next.js/React where appropriate.
- Optimise it for mobile, speed, accessibility, and SEO.

Do not present the original layer as your own design. For client or commercial use, use a GetLayers plan that includes commercial rights.

## Portfolio project page format

For each demo, show:

- The business problem
- The final website (live link and screenshots)
- Main features
- Your process and technology used
- A note: “Concept project created by Alexion Studios.”
