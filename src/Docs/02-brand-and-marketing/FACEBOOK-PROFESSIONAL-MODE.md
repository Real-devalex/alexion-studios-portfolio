# Facebook Professional Mode Setup

Professional mode can work well for a founder-led business: people hire people they trust. Keep the profile professional but human.

## Profile checklist

- [ ] Use a clear, friendly headshot with good lighting.
- [ ] Use a cover image that says what you do: “Web Development • Game Development • Digital Solutions”.
- [ ] Set your name clearly and consistently.
- [ ] Add this bio (edit location/contact details):

> Founder at Alexion Studios. I build modern websites, web apps, games, and digital solutions. Available for freelance projects and collaborations.

- [ ] Add your portfolio/GitHub/LinkedIn link when ready.
- [ ] Add a business email address.
- [ ] Turn on the professional dashboard and review insights weekly.
- [ ] Pin an introduction post.

## Pinned introduction post (draft)

> Hi, I’m [Name], the founder of Alexion Studios. I help businesses, creators, and teams turn ideas into useful digital products — from modern websites and web apps to games and content support.
>
> My core tools include React, JavaScript, Node.js, PHP, Python, C++, and C#. I’ll be sharing projects, useful tech tips, and behind-the-scenes progress here.
>
> If you need a website, a developer for a project, or want to collaborate, send me a message.

## Rules for a strong profile

- Show your real work more than motivational quotes.
- Use screenshots, short videos, and before/after results.
- Write simply: what you built, who it helps, and what problem it solves.
- Reply quickly and professionally to comments and messages.
- Never post client details without permission.
